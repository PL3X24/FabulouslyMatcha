# Matcha Flavoured

The Matcha Flavoured datapack, packed with most of the big optimization mods paired with some quality of life addons.

Tuned for performance and focused on the experience Matcha Flavoured has to offer. No content or big core gameplay changes are added to keep save files as vanilla as possible.

## Features

Based on Fabulously Optimized, this modpack offers great optimization for intense resource scenarios e.g. generating chunks.

- Matcha Flavoured loads automatically when creating new saves.
- Built-in support for shaders.
- Extreme render distances.
- Enhanced audio reverb and sound occlusion.
- Tons of HUD and UI additions.
- Inventory sorting and more.

## Important notes

- This modpack includes Distant Horizons. Changing your GC and Java fork to a high performance one (GraalVM and ZGC) is highly recommended.
- 4 - 6GB of RAM minimum for Distant Horizons to work.
